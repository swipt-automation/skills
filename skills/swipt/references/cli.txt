Swipt CLI

usage: swipt COMMAND

commands:
  project   Make, build and deploy swiplet projects
  device    Manage the devices and read their logs
  swiplet   Manage the swiplets on the device
  repl      Run JavaScript in the REPL session on the device
  sideload  Sideload Swipt
  version   Print the version

options:
  -h, --help  help

Make, build and deploy swiplet projects

usage: swipt project COMMAND

commands:
  create DIRECTORY     Make a swiplet project in a new or empty directory
  build [PROJECT]      Bundle the project into dist/<swiplet.id>.swiplet
  source [SWIPLET...]  Collect the built swiplets into dist/ with a swiplets.json
  deploy [PROJECT]     Build the project and install it on the device
  develop [PROJECT]    Build, install and follow a swiplet project as it changes

options:
  -h, --help  help

Make a swiplet project in a new or empty directory

usage: swipt project create DIRECTORY

options:
  -h, --help  help

Run JavaScript in the REPL session on the device

usage: swipt repl COMMAND

commands:
  run [CODE | FILE [ARG...] | - [ARG...]]  Run a JavaScript expression or program on the device
  reset                                    Reset the session
  api                                      Print the TypeScript declarations of the globals and modules
  data                                     Manage the files in the data directory of the REPL

options:
  -d, --device NAME|URL  the device to use
  -h, --help             help

Run a JavaScript expression or program on the device

usage: swipt repl run [CODE | FILE [ARG...] | - [ARG...]]

The first argument is FILE when it names an existing file and CODE otherwise; options go before it.
CODE is an expression whose value is printed. FILE, or standard input given as - or no argument, is a program, and only its console output is printed.

options:
  -d, --device NAME|URL  the device to use
  --output DIRECTORY     image directory (default: a new temporary directory)
  -h, --help             help

Reset the session

usage: swipt repl reset

options:
  -d, --device NAME|URL  the device to use
  -h, --help             help

Sideload Swipt

usage: swipt sideload COMMAND

commands:
  install    Install Swipt
  update     Update or renew Swipt
  uninstall  Remove Swipt

options:
  -d, --device NAME|UDID  device paired with this Mac
  --team ID               team ID, required if more than one
  -h, --help              help

Install Swipt

usage: swipt sideload install

options:
  -d, --device NAME|UDID  device paired with this Mac
  --team ID               team ID, required if more than one
  --passcode CODE         set up auto-unlock with this passcode
  --passcode-type TYPE    pin (4 or 6 digits, default), numeric or alphanumeric
  --nightly               use nightly build
  --no-setup              do not pair Swipt, trust its developer or publish its API
  --no-setup-pair         do not pair Swipt
  --no-setup-api          do not publish the API to the local network
  -h, --help              help

Update or renew Swipt

usage: swipt sideload update

options:
  -d, --device NAME|UDID  device paired with this Mac
  --team ID               team ID, required if more than one
  --passcode CODE         unlock device with this passcode
  --passcode-type TYPE    pin (4 or 6 digits, default), numeric or alphanumeric
  --nightly               use nightly build
  --no-setup              do not pair Swipt, trust its developer or publish its API
  --no-setup-pair         do not pair Swipt
  --no-setup-api          do not publish the API to the local network
  -h, --help              help
